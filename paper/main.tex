\begin{abstract}
\noindent
After the devastating March 2025 earthquake in Myanmar, I wanted to understand how many of the country's 254 dams are actually at risk.
This write-up documents a hobby project that pulls earthquake data from a public API, scores every dam for seismic risk, and runs probabilistic hazard analysis---all with open-source Python tools.
The Abrahamson \& Silva (2008) ground-motion model is compared with a small set of instrumental recordings using event-specific rupture distances and site conditions. The heuristic screening grades classify \HighPercent\% of the inventory as Critical or High; these grades are not probabilities of dam failure.
An OpenStreetMap-based scenario analysis estimates PGA above 0.1$g$ at \SchoolCount{} schools and \HospitalCount{} hospitals. These are modeled exposures, not observed damage.
Everything---code, data, interactive maps---is on GitHub.
\end{abstract}

\section{Background}
% ============================================================

On March 28, 2025, a magnitude 7.7 earthquake hit central Myanmar along the Sagaing Fault.
The rupture was enormous---475~km of surface break, supershear velocity, 5--7~m of slip.
The archived Naypyidaw station has two horizontal PGA peaks near 0.57$g$ and 0.62$g$; their geometric mean is about 0.60$g$. The vertical peak is a different component and must not be compared directly with a horizontal GMPE. This paper does not establish disaster casualty totals or observed dam-damage counts.

Myanmar has at least 254 documented dams (irrigation, hydropower, multi-purpose), many built before modern seismic codes existed.
The Sagaing Fault runs right through the middle of the country where most of these dams are.
I wanted to know: which dams are most at risk, and can we quantify it with open data?

\subsection{What This Project Does}

\begin{itemize}
    \item Pulls \CatalogCount{} earthquake records (through \CatalogLatest) from the \href{https://mmeq.akze.net}{Myanmar Earthquake API}
    \item Scores all 254 dams for seismic risk using a proper ground-motion model
    \item Runs probabilistic hazard curves, Coulomb stress transfer, fragility analysis
    \item Validates predictions against actual recorded ground motions
    \item Publishes everything as an open-source toolkit with interactive maps
\end{itemize}

\subsection{b-Value and Catalog Completeness}

The Gutenberg-Richter law says $\log_{10} N = a - bM$.
The tricky part is that the catalog is incomplete at small magnitudes---the 1970s network couldn't detect M2 events, but the modern network can.
Fitting the full catalog with automatic completeness gives $b = \RawB$ at $M_c = \RawMc$. After Gardner-Knopoff (1974) declustering, $M_c = \DeclusteredMc$ and $b = \DeclusteredB$; these are the rates used for the probabilistic hazard below. A plausible b-value alone does not establish catalog completeness or a stationary Poisson process.

A stability analysis (Figure~\ref{fig:fmd}b) shows the b-value stabilizes around $M_c \approx 4.0$--$4.5$; the headline fit uses $M_c = 4.0$.
Using that cutoff: $b = \FixedB$ with \FixedCount{} events. No confidence interval is asserted here without accounting for catalog heterogeneity and magnitude uncertainty.

\section{Ground Motion: Getting the GMPE Right}
% ============================================================

This is where I spent the most time.
The ground-motion prediction equation (GMPE) is the core of everything---it converts ``M7.7 earthquake at X~km distance'' into ``PGA = Y$g$ at this dam.''

\subsection{Abrahamson \& Silva (2008)}

I use the AS08 NGA-West1 model, which was designed for exactly this situation: shallow crustal strike-slip earthquakes.
The full model has 6 terms:

\begin{equation}
    \ln(\text{PGA}) = f_1(M, R_{rup}) + f_{style} + f_{site}(V_{S30}, \text{PGA}_{1100}) + f_{HW} + f_{ZTOR} + f_{large}
\end{equation}

The coefficients ($a_1 = 0.804$, $a_2 = -0.9679$, $c_1 = 6.75$, $c_4 = 4.5$, $V_{LIN} = 865.1$, $b = -1.186$, etc.) are from Tables 4--5a. An independent computation with \href{https://github.com/gem/oq-engine/blob/master/openquake/hazardlib/gsim/abrahamson_silva_2008.py}{OpenQuake 3.26.2} agrees to numerical precision on 80 vertical strike-slip cases spanning M5--8, distances 1--200\,km, and $V_{S30}=180$--1100\,m/s, with default basin depth. This checks implementation parity for those cases, not the applicability of AS08 to Myanmar. The local simplified hanging-wall term is not validated for dipping faults.

The nonlinear site response is important---it depends on both $V_{S30}$ and the rock-site PGA, so soft soil sites don't just scale linearly.

\subsection{Validation Against Actual Recordings}

The archived USGS ShakeMap station list contains six instrumental stations.
PANO's horizontal PGA values are flagged as outliers and are excluded, leaving \StationCount{} clean horizontal pairs (Table~\ref{tab:validation}). We use the event-specific \texttt{distances.rrup}, \texttt{distances.rjb}, and station \texttt{vs30} supplied by USGS, rather than distance to an unrelated mapped fault.
Observed PGA is the geometric mean of the two unflagged horizontal component peaks, not the first channel (which may be vertical). This is an approximation to AS08's rotation-independent GMRotI50; the exact component requires time histories and cannot be reconstructed from scalar peaks alone.

An earlier version assigned KTN a 2.3\,km distance to an unrelated active fault, despite the supplied event-rupture distance being 370.594\,km, and misidentified its vertical channel as the observation. The resulting ``50-fold overprediction'' and claim that KTN was an interpolated grid value were artifacts of the comparison, not supported scientific conclusions.
Modeled dam PGA is excluded from the observed-data table: comparing one prediction with another is not independent validation. The table is generated directly from the station diagnostic on every publication build.

\subsection{Site-Specific Vs30}

Instead of assuming all dams sit on rock ($V_{S30} = 760$\,m/s), I sampled $V_{S30}$ at each site from the USGS ShakeMap $V_{S30}$ grid (a Wald \& Allen 2007 topographic-slope proxy).
Values range from \VsMin{} to \VsMax{}\,m/s (mean \VsMean{}\,m/s). These are site proxies, not measured geotechnical profiles; nonlinear amplification depends on both site velocity and input shaking.

\section{Dam Risk Scoring}
% ============================================================

Each dam gets a composite score (0--10) from four components:

\begin{equation}
    R = 0.35 \times S_{seismic} + 0.30 \times S_{fault} + 0.20 \times S_{proximity} + 0.15 \times S_{exposure}
\end{equation}

Here $S_{seismic}$ is PGA-based. The fault score uses distance to a mapped fault or plate boundary; the proximity score uses distance to the 2025 epicenter. The exposure score combines inventory height, capacity, and storage.
The screening traces are not a complete active-fault inventory and are distinct from the actual event rupture used for scenario PGA.

\subsection{Sensitivity to Weights}

The weights (0.35/0.30/0.20/0.15) are somewhat arbitrary, so I ran 100 Monte Carlo iterations with random Dirichlet-sampled weights.
The median Critical+High fraction across draws is $\sim$67\%, but the grading is genuinely weight-sensitive: 22 of the 100 draws fall below a 30\% Critical+High fraction (minimum $\sim$12\%, 5th percentile $\sim$17\%), typically when the proximity weight dominates. The headline conclusion---that a substantial fraction of the portfolio carries elevated risk---holds for the large majority of weightings, but the exact grade counts should be read as conditional on the chosen weights.

\section{Probabilistic Hazard}
% ============================================================

Beyond the single-event PGA, the Cornell-McGuire-style calculation integrates the G-R magnitude distribution and GMPE over the sampled M5--8 range, with fixed log-ground-motion variability ($\sigma_{ln} = 0.65$).

The 475-year PGA (approximately 10\% chance of exceedance in 50 years under a stationary Poisson model) ranges from \HazardMin$g$ to \HazardMax$g$, with a mean of \HazardMean$g$. The Frankel (1995)-style smoothed-seismicity source model uses the declustered catalog ($b = \DeclusteredB$) and integrates over source-to-site distance.
\HazardAboveOne{} dams exceed 0.1$g$ and \HazardAboveTwo{} exceed 0.2$g$. Annual exceedance \emph{rate} $\lambda$ is distinct from annual probability $1-e^{-\lambda}$; the export now distinguishes these fields.
These are \emph{catalog-only estimates}: there is no fault-source recurrence term, and a single regional completeness model is applied despite network and temporal heterogeneity. AS08 is also extrapolated for distant source cells. Comparisons with Yang et al.\ (2023) and GEM are contextual only: their source models, locations, site conditions, and assumptions differ. Agreement in regional ranges does not validate this model or establish it as a lower bound.

\section{Coulomb Stress Transfer}
% ============================================================

After a big earthquake, the stress field changes.
Some areas get loaded (more likely to have aftershocks), others get unloaded (``stress shadow'').
I modeled this using the point-source double-couple summation from Aki \& Richards (2002).

The default calculation does \emph{not} use the archived USGS 530-patch variable-slip solution. It constructs seven segments from an idealized Sagaing trace, divides them into patches, and assigns uniform slip from the M7.7 scalar moment (about 568\,km total length and 1.56\,m slip). This is a simplified point-source stress proxy, not a full elastic half-space solution.
At $\pm$0.01\,MPa, 16 dam locations are labeled positive (``Triggered'') and 72 negative (``Shadow''). These describe the assumed crustal receiver geometry, not structural loading or a dam-failure probability. The four-lobed pattern and a symmetry test do not independently validate the stress amplitudes.

\subsection{Monte Carlo PGA Uncertainty}

The GMPE has aleatory uncertainty ($\sigma_{ln} = 0.65$), meaning the actual PGA at any site could easily be 2$\times$ higher or lower than the median.
The pipeline draws 1,000 lognormal samples per dam. These illustrate conditional ground-motion variability, not epistemic uncertainty in the source model, an annual event probability, or the probability of dam failure; current results are in \texttt{docs/report/monte\_carlo\_pga.csv}.

\section{Building Exposure from OpenStreetMap}
% ============================================================

The OSM inventory contains \BuildingCount{} infrastructure elements, including schools, hospitals, and places of worship. These are mapped elements, not necessarily unique physical buildings or a complete census.
For each element, the scenario uses distance to the actual 2025 rupture projection only, not to unrelated plate boundaries. The surface projection is an approximation to rupture-plane distance for the near-vertical fault.
Modeled PGA-to-intensity bins place \BuildingSevere{} elements in Severe (VIII) and \BuildingVeryStrong{} in Very Strong (VII); \SchoolCount{} schools and \HospitalCount{} hospitals have modeled PGA above 0.1$g$. These are scenario estimates, not observations of shaking or damage.

Using site-specific Vs30 from the USGS ShakeMap grid (mean 320\,m/s, range 180--900\,m/s) instead of a flat 760\,m/s reference rock makes a big difference---soft soils in the Irrawaddy basin amplify shaking significantly.

The repository lacks measured construction classes, occupancy, vulnerability, and damage observations sufficient for casualty estimation. The exploratory loss helper uses assumed coefficients and is not a verified HAZUS implementation; its outputs are not published here as injury, hospitalization, or collapse forecasts. Supershear/directivity effects are not modeled, but they do not justify attributing every residual to systematic underprediction.

\section{What I Learned}
% ============================================================

\begin{enumerate}
    \item \textbf{Getting the GMPE right matters a lot.}
    The original implementation had wrong coefficients (a1 = $-$0.526 instead of 0.804) and no site response.
    Correct coefficients are necessary but not sufficient: component choice, rupture distance, quality flags, and site conditions must also match when checking observations.

    \item \textbf{Catalog completeness is sneaky.}
    The raw b-value of 0.34 looked alarming but was just an artifact of mixing 1970s data (only M4.5+ detected) with 2020s data (M2+ detected) and the 2025 aftershock burst.
    A second caveat: the catalog pools magnitude types (\raise.17ex\hbox{$\scriptstyle\sim$}74\% $m_l$, \raise.17ex\hbox{$\scriptstyle\sim$}22\% $m_b$, \raise.17ex\hbox{$\scriptstyle\sim$}2\% $M_w$) without converting to a common moment-magnitude scale, so the FMD slope carries some inter-scale bias on top of the completeness effect.
    Always check stability before trusting a b-value.

    \item \textbf{Screening is not a safety assessment.}
    \HighCount{} inventory entries (\HighPercent\%) meet the chosen Critical/High thresholds. This inventory is not all Myanmar dams, and these heuristic grades do not demonstrate observed damage or structural failure risk.

    \item \textbf{Open data makes this possible.}
    USGS ShakeMap, GEM faults, WorldPop, Copernicus DEM, Open Development Mekong---all free, all accessible via API or download.
    A hobby project can do real seismic hazard analysis.

    \item \textbf{Validation is essential.}
    Without the ShakeMap station comparison, I wouldn't have caught the GMPE coefficient errors.
    A near-fault recording is useful, but one station cannot establish the validity of all downstream models.
\end{enumerate}

\subsection{Limitations}

This is a hobby project, not a professional PSHA. Key caveats:

\begin{itemize}
    \item No actual dam structural data (age, construction quality, foundation)
    \item Fragility curves use generic HAZUS parameters, not Myanmar-specific
    \item The AS08 model doesn't account for directivity (the supershear rupture would amplify PGA in the forward direction)
    \item Only \StationCount{} unflagged horizontal station pairs, with \InRangeStations{} within 200\,km; geometric-mean peaks approximate GMRotI50
    \item Mixed magnitude types, nonuniform completeness, simplified source depths and rupture geometry, and uncalibrated screening weights
    \item The Coulomb model uses a simplified point-source approach, not the full Okada (1992) elastic half-space
\end{itemize}

\section{How to Use the Code}
% ============================================================

Everything is at \url{https://github.com/akzedevops/mmeqopendata}.

\begin{verbatim}
git clone https://github.com/akzedevops/mmeqopendata.git
cd mmeqopendata
pip install -e ".[dev]"

mmeq export                    # fetch earthquake data
mmeq report --output ./report  # run everything
\end{verbatim}

The \texttt{mmeq report} command generates maps, reports, dam scores, hazard curves, and exposure estimates. Run \texttt{python tools/build\_figure\_data.py} first for sensitivity inputs; \texttt{mmeq publish} synchronizes the paper tables, site downloads, and README with the generated report.

Live dashboard: \url{https://akzedevops.github.io/mmeqopendata/}
